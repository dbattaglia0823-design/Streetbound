# Phase 6 — World Validation Center

World settings → World Validation Center. Run checks, inspect findings by double-click, repair selected or all eligible small endpoint gaps as one undoable source transaction, and export the revision-tagged JSON readiness report to user://world-validation-report.json. Repairs only propose mutually unique pairs of nearby same-layer compatible endpoints; inspect intent before applying. No world is published or automatically rebaked.

Custom maps use the production scratch compiler and current directed lanes. Morrow requires the current baked graph; changed road or junction drafts must be baked before route validation. Checks include separated lane components, junction lanes without successors, elevation rules, coincident source props, marker access, ordered race legs including circuit closure, and contract/robbery legs. Lane access threshold is 25 m; proximity does not prove collision-free access. Separate lane components and coincident props are warnings, not necessarily defects. Reports include matching measured Test Drive frame/build/draw peaks, not GPU timings, and three relative traffic-demand screens with patrol-disabled lane counts.

Directed navigation preview plots a legal route on the selected start and destination levels. This is route geometry, not a physical drive. Static checks clear is not release certification. Real AI drives, traffic queue and emergency response simulations, alternate routing, full building footprint checks and automated performance stress runs remain follow-up work. ## Physical Test Drive

The navigation preview can launch a real, bounded AI drive of a ground-level route (20–5000 m; up to 180 seconds). It uses the existing vehicle controller, racing AI, physical collisions and actual ambient traffic. Normal/rush/heavy set base traffic budgets of 16/24/30 before district scaling. Police mode requests a real level-one pursuit after three seconds and observes first dispatch and first same-layer officer within 50 m; -1 means not observed. Actual peak traffic and stopped traffic are sampled, not a network-wide congestion model. On completion, timeout, off-route or manual return, the source-tagged report includes collisions, off-road time, stuck events, progress and cross-track error. Existing Test Drive profiling supplies frame/chunk/draw measurements. Report is available in the Validation Center for the matching source only. The test does not modify the production map or career save. No automated multipoint batch runner, alternate route planner, or GPU benchmark is provided. Live validation is pending.
