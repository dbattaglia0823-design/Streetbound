# Phase 10 — World Release Center

Open World Settings → World Release Center, or Ctrl+K → World Release Center. Save a custom map before preflight/export. Preflight runs the exact production compiler without changing the active PLAY map. It checks spawn clearance, source rules, required project artwork, baked index membership, weak road components, and peak chunk assignments. Warnings are not automatic failures; isolated tracks can be intentional. Real directed route validation, physical driving and target hardware profiling remain separate.

Export creates a ZIP under the local map library's releases directory containing the exact source, immutable production archive, explicit referenced project artwork and a SHA-256/size manifest. It does not contain the base game, built-in atlases or all game dependencies. Verify ZIP reads the package without extracting or activating it, checks names, bounded sizes, all payload hashes, world identity and structural integrity. Publish through the existing explicit Build Game World confirmation. A publish embeds artwork checksums into the archive; the existing multiplayer archive fingerprint now changes when a referenced asset changes and the map is republished. It does not validate arbitrary locally altered game assets at lobby join. Players still need the same compatible game build and exact published map; no automatic peer download or installation.

Automatic backups preserve previous saved custom map bytes before a changed save, retain the latest 12 per filename, and fail closed if the backup cannot be written. Unchanged saves do not create backups. Compare selected backup against the current draft by entity ID; restore into the draft is undoable. Existing named snapshots also support comparison. Historical publication rollback validates archive/source checksums and, for new packages, artwork hashes before switching the active pointer; the prior active selection is backed up. Career saves are not changed.

Streaming keeps the original 3x3 active and 5x5 resident bounds (union in split screen). Missing archive cells are skipped, eviction disables collision first, and optional single-player forward prefetch warms one dormant ring cell when active work is done and frame time is below 20 ms. F7 shows actual build/reuse/prefetch/pending counts. No physics timestep, view distance or handling changes. This is a bounded scheduling optimization, not a measured FPS guarantee.

Tests: tests/world_release_test.py and tests/map_release_test.gd, existing publish/streaming tests. CI and interactive verification pending.
