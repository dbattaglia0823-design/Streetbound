# Road-linked guardrails

Select a ground-level road in the native editor, open Auto guardrails in the road inspector, enable Left and/or Right, set independent start/end percentages, and apply. Left/right follow the stored control-point direction. Remove either side by unchecking it; Remove both sides clears both when applied. Undo and redo restore the source settings. The preview is approximate; Test Drive and publishing compile from the actual baked road splines and junctions, leaving conservative gaps at intersections, merging ramps, neighboring pavement and map edges. The existing solid guardrail collision and streaming code handles the resulting paths. Manual guardrails are unchanged. Browser source import/export preserves settings; the native inspector provides the editing controls. Ground-level roads only: existing elevated deck/bridge rails are separate. Remove linked rails before splitting a road, then configure the new roads. Percentages follow road length after reshaping. No stock map data changes are made.
