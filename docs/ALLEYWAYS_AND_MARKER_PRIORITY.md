# Alley access and traffic priority validation

Alleyways remain drivable physical roads for players. Ambient lane generation excludes alley roads, including the traffic preview, spawn candidates and turn links. Police use a separate alley-capable pursuit graph when necessary; their normal reinforcement spawn and roadblock selection remain on ordinary traffic roads. Player navigation can still route through alleys. Ordinary road junction geometry remains intact. Alley road paint, lane-wear stripes and junction approach paint are suppressed; unpainted surfaces and physical curbs remain.

The native marker validator accepts whole numeric values from 1 to 10, but the Python compiler previously required the JSON value to be a Python int. Godot can write e.g. 3.0 after an edit or JSON round-trip. The compiler now accepts finite integral numeric values in range and rejects fractions, booleans, strings and values outside the range. Remaining errors include the marker ID, name and invalid value. Existing valid local maps can be saved/baked again without manually changing all markers. The user's City Center file is local and was not included in the repository; its exact marker was not inspected.
