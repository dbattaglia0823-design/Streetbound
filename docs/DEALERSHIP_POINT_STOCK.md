# Dealership point stock and collision balance

In World Builder, select a dealership game marker and open its Customize Point / Edit Selected Marker dialog. Save the marker type and linked dealership (if any), reopen the marker, and choose **Edit Dealership Stock...**. Search the playable catalog, toggle individual cars, or use Add all visible / Remove all visible / Clear stock. Apply stock and save the map. Linked markers update the real dealership's stock; unlinked dealership markers with a configured inventory operate as a standalone showroom at that marker. Both use the normal purchase UI, catalog prices, driver-level restrictions and ownership; marker showrooms require the marker's radius, speed, unlock, road layer, opening hours and no active pursuit/race/contract. Empty inventory is valid. Existing unconfigured markers retain their old behavior. Custom maps show only their own explicitly placed dealership records.

Impact HP loss is multiplied by 0.30 in the common vehicle damage model, including the capped impact and existing upgrade multipliers. Existing one-point minimum/rounding and remaining-health clamp remain. Maximum health, condition thresholds and previous save values are unchanged. Regression expectations updated for reduced impact losses.

The marker stock dialog has a view-only sort dropdown (A-Z, Z-A, Price High, Price Low). Prices use numeric catalog values and name/ID tie-breaks are deterministic. Search, hidden selections, and the saved inventory are independent of sorting.
